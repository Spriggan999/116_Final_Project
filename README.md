# EECS 116 Final Project

Project source for the HyperDrone visual-inertial odometry experiments.

- [`viobench/`](viobench/README.md): benchmark framework and setup instructions.
- [`1_generative_ssm`](viobench/viobench/solution/examples/python/1_generative_ssm/README.md): generative embedding/state models, streaming collection, training, evaluation, and verification results.

Generated build files, model checkpoints, recordings, caches, and local credentials are excluded from Git. Keep separate backups of trained model weights.
